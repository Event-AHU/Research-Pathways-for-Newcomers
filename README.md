## 📐 数学基础：临时抱佛脚，也得抱紧！

扎实的数学功底是理解模型本质的前提：
- 高等数学（微积分、级数）
- 线性代数（矩阵、特征值、SVD）
- 矩阵分析（范数、条件数、矩阵微分）
- 概率论与统计（贝叶斯、分布、MLE/MAP）

> ⚠️ 建议：不要只记公式，要理解其几何意义与应用场景。
