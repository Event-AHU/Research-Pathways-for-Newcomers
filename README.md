## 💡 思想准备：觉悟决定高度

- ✨ **学习是为了自己，不是为导师打工！**  
  知识和技能是伴随你一生的资产。没有这个觉悟，建议先“回炉重造”。

- 🔥 **科研靠自驱，不靠他驱！**  
  被动等待指令的人，很难在科研路上走得长远。主动思考、主动探索，才是科研人的基本素养。

## 📐 数学基础：临时抱佛脚，也得抱紧！

扎实的数学功底是理解模型本质的前提：
- 高等数学（微积分、级数）
- 线性代数（矩阵、特征值、SVD）
- 矩阵分析（范数、条件数、矩阵微分）
- 概率论与统计（贝叶斯、分布、MLE/MAP）

> ⚠️ 建议：不要只记公式，要理解其几何意义与应用场景。
